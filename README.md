# 📚 学习进度统计软件

一款基于**微软 .NET 10 + WinUI 3** 构建的 Windows 11 桌面应用，用于统计和管理**每周学习进度**。采用微软最新的 **WinUI 3** 原生界面框架（NavigationView 导航、Mica 质感、流畅动画），打包为**原生 Windows 桌面 exe**，无需联网、无需安装运行时即可运行。

## 🚀 快速开始（Windows 11）

### 方式一：安装包（推荐）

1. 打开 `安装包` 文件夹，双击 **`学习进度统计_安装包_v1.1.0.exe`**；
2. 按提示点击「下一步」完成安装（无需管理员权限）；
3. 安装后自动创建**桌面快捷方式**和**开始菜单**入口，双击即可运行；
4. 如需卸载，到「设置 → 应用」或开始菜单中运行「卸载学习进度统计」。

> 💡 安装版数据保存在 `%LOCALAPPDATA%\StudyTracker`，卸载软件不会删除你的学习数据。

### 方式二：绿色便携版

1. 打开 `发布版` 文件夹，双击 **`启动学习进度统计.lnk`**（或 `StudyTracker.exe`）即可运行；
2. 可以把 `发布版` 整个文件夹拷到任意位置（如 U 盘）使用。

> 首次打开会提示还没有科目，请先到左侧 **「科目管理」** 添加学习科目（例如：高等数学、英语、Python…），然后回到 **「本周打卡」** 页面，点击任意格子即可记录每天每科的学习情况。

## ✨ 功能一览

### 📅 本周打卡（主界面）
- 科目 × 一周7天 打卡网格，点击格子填写：**学习时长、完成度%、是否完成、备注**
- 快捷 `+0.5h / +1h / +1.5h / +2h` 按钮
- 顶部周导航：上一周 / 下一周 / 回到本周
- 每日总学时汇总行、科目周进度条（绿/黄/红三色状态）
- 今日未打卡科目提醒

### ✅ 待办任务
- 任务清单：新增 / 编辑 / 删除 / 勾选完成
- 支持关联科目、优先级（高/中/低）、截止日期、备注
- 自动标记**已逾期**（红）与**今日到期**（橙），顶部统计卡展示待办/今日到期/已逾期/完成率
- 完成的任务可一键恢复，列表支持上移 / 下移排序
- 主页顶部有「今日待办」提醒条，一键跳转到待办页
- 随 JSON 备份一起导出 / 导入

### 📊 统计分析
- 指标卡：累计总学时、学习总天数、当前/历史最长连续打卡、最常学科目
- 近 12 周总学时趋势图（ECharts）
- 本周各科目实际学时 vs 周目标对比图
- 近 12 周时间分配饼图
- 各科目近 8 周趋势折线图
- 近 14 周 GitHub 风格每日学习热力图
- 周内每天平均学时分布
- **自动适配深浅色主题**：深色模式下图表切换深色配色

### 📝 周报总结
- 自动生成周报：本周概览、各科目明细、未达标提醒、与上周对比、下周建议
- 可编辑「本周复盘」并保存，下次自动带入
- 导出 **HTML 周报 / TXT / Excel 报表**（Excel 含周汇总、学习明细、科目设置 3 个工作表）

### ⏳ 日期倒计时
- 为考试、交作业、重要纪念日等设置倒计时事件
- 自动计算剩余天数并分级提醒：**7 天内红色**、**8-30 天橙色**、30 天以上蓝色、过期置灰
- 支持自定义颜色、备注，可排序、编辑、删除
- 主页顶部显示「最近倒计时」提醒条，一键跳转
- 随 JSON 备份一起导出 / 导入

### 🍅 番茄钟
- 专注 / 短休息 / 长休息计时（时长可在设置中调整）
- 完成后自动统计今日番茄数与专注分钟数
- 一键把本次专注计入某个科目的今日记录

### 📚 科目管理
- 新增 / 编辑 / 删除科目，自定义颜色、周目标学时、优先级、说明
- 上移 / 下移排序，归档（保留历史记录）

### 💾 数据管理
- 导出 Excel / CSV / JSON 备份
- 导入 JSON 备份
- 数据库一键备份与恢复
- 清空所有数据（危险操作需确认）

### 🪟 退出到托盘
- 关闭窗口时可选择：**最小化到托盘** / 退出程序 / 取消
- 最小化到托盘后程序在后台继续运行（番茄钟、数据统计不受影响）
- 系统托盘图标：**左键双击**恢复窗口，**右键菜单**可显示主窗口或退出
- 默认行为可在「设置 → 关闭窗口时」调整（每次询问 / 最小化到托盘 / 直接退出）

### ⚙️ 设置
- 每周起始日（周一 / 周日）
- **界面主题**：浅色 / 深色 / 跟随系统（浅色纯色背景，深色带 WinUI Mica 质感）
- 界面主题色（8 种预设 + 自定义）
- 新增科目默认周目标
- 启动时本周目标提醒开关
- 番茄钟各阶段时长

## 📦 版本更新规则（重要）

- 每次发布新版本，新安装包放入 `安装包` 目录，**文件名必须带版本号**（如 `学习进度统计_安装包_v1.3.0.exe`）；
- **旧版本安装包一律保留，不得删除**，方便随时回退到任意历史版本；
- 版本记录见 `安装包\版本记录.txt`，发布新版本时请追加对应记录；
- 版本号在 `StudyTrackerWinUI\StudyTrackerWinUI.csproj` 的 `<Version>` 和 `setup.iss` 的 `MyAppVersion` 中统一修改。

## ❓ 常见问题

- **浅色/深色主题怎么切换？** 设置 → 界面主题。浅色主题使用纯色背景，深色/跟随系统使用 WinUI 3 的 Mica 毛玻璃质感（跟随系统时若系统为深色，Mica 保持深色）。
- **为什么 exe 是英文名 StudyTracker.exe？** 经测试，部分 .NET 桌面应用在**中文文件名**下会异常退出（兼容问题），使用英文 exe 名 + 中文快捷方式最稳定。
- **数据存在哪？** 安装版在 `%LOCALAPPDATA%\StudyTracker\study_progress.db`；便携版在 `发布版\data`。备份导出文件在 `data\backups`、`data\exports`。卸载软件不会删除数据。
- **需要联网吗？** 完全不需要，所有功能本地运行。
- **需要安装 .NET 吗？** 不需要，发布版已自包含运行时。
