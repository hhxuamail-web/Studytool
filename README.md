# 📱 学习进度统计 · Android 版

**版本：v2.0.0** ｜ 适用于 Android 8.0 及以上（arm64）

一款帮你**统计每周学习进度**的安卓应用：记录每天每科的学习时长，自动生成统计图表与周报，还带待办、倒计时和番茄钟。
界面采用 **Google Material Design 3** 设计，浅色/深色自动适配。

---

## 📦 怎么安装

1. 把 `学习进度统计_安卓版_v2.1.0.apk` 传到手机（微信/QQ/数据线都行）
2. 点击文件 → 安装
3. 首次安装若提示「未知来源应用」，到系统设置里允许后重试

> 💡 升级前请先备份数据（见下），卸载会清除数据。

---

## 🚀 第一次使用

1. 打开 App → 底部「我的」→「科目管理」→ 添加科目（如：高等数学、英语），设置每周目标
2. 回「首页」→ 点击日期格子 → 填写学习时长 → 保存
3. 数据会自动汇总到首页统计卡、进度环，以及「统计」页的图表

---

## 📊 都有哪些功能

| 功能 | 怎么用 |
|---|---|
| 📅 本周打卡 | 首页点格子记录每天每科学时，支持 +0.5h/+1h 快捷添加 |
| ✅ 待办任务 | 安排每日任务，逾期红色提醒，勾选即完成 |
| 📊 统计分析 | 6 张原生图表：趋势、周内分布、实际vs目标、饼图、多科目趋势、热力图 |
| 📝 周报总结 | 自动生成每周报告，可编辑复盘，导出 HTML/TXT |
| 📚 科目管理 | 管理科目颜色、周目标、优先级 |
| ⏳ 倒计时 | 记录考试/纪念日，临近自动变红提醒 |
| 🍅 番茄钟 | 25 分钟专注 + 休息，到点振动提醒；页内可自定义时长 |
| 🗄️ 数据管理 | 备份/恢复，导出 Excel/CSV/HTML |
| ⚙️ 设置 | 周起始日、默认周目标等（界面自动跟随系统深浅色） |

竖屏/横屏都做了适配，转过来自动重排。

---

## 💾 备份数据（重要）

- 数据存在应用内部，**卸载应用会全部清除**
- 请定期：数据管理 → 「导出 JSON 备份」→ 用系统分享保存到手机/网盘
- 换机/重装后：数据管理 → 「导入 JSON 备份」恢复

---

## 🐛 遇到问题？

**打开闪退？**
- 本版本已做加固：不会直接退出，会弹窗显示错误内容
- 请把弹窗内容**截图**反馈，或告知手机品牌/型号 + Android 版本

**安装提示未知来源？**
- 系统设置 → 安全 → 允许安装未知应用

**提示 ABI 不匹配？**
- 说明设备不是常见 arm64 架构，反馈型号后可补发对应版本
